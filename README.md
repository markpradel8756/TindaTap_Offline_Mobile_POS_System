# TindaTap v1.0.0

**Offline POS and inventory app for sari-sari stores.**

## Key Features

- Works fully offline
- Inventory and stock tracking
- POS checkout and sales history
- QR code generation
- Database backup/export

## Requirements

- Android 6.0+ (API 21+)
- About 50 MB free storage

## Install

### APK

1. Download the APK to your device
2. Open it from your file manager
3. Allow required permissions
4. Tap Install

### From Source

1. Install Flutter 3.16+
2. Run `flutter pub get`
3. Connect an Android device or emulator
4. Run `flutter run`

## Usage

1. Add products
2. Update stock
3. Process sales in POS
4. Review reports
5. Back up data regularly

## Notes

- Data is stored locally in SQLite
- Internet is not required
- Storage permission may be needed for backups and QR codes

# TindaTap

Offline-first POS and inventory app for sari-sari store owners.

## Run

1. Install Flutter 3.16+.
2. From this project folder, run flutter pub get.
3. Launch on an Android device or emulator with flutter run.

## Notes

- All data is stored locally in SQLite.
- First launch shows the store setup screen.
- QR images are copied into the app documents directory.
- Backups are manual: use the export button in Settings to share the database file.
